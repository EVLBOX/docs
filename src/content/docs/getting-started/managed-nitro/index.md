# What is Nitro Management?

![nitro-control-panel-logo](/nitro/nitro-panel-text.png.webp)

Our dedicated server and Gaming VPS customers have the option to make their services Nitro Managed. Nitro Panel is EVLBOX's highly modified version of the popular open-source project [Pterodactyl Panel](https://pterodactyl.io/) 

### Nitro Panel Features for Nitro Managed customers

- Create game servers from our [supported list of games](/getting-started/managed-nitro/supported-games)
- Slick mobile friendly interface
- One click PHPMyadmin login (for game server databases) 
- Minecraft Modpack installer 
- Minecraft Player Manager
- Off-site backup/restore tool
- Manage permissions of sub-users (let your friends start/stop your servers!)
- Create subdomains on the fly (evlbox.io) and map them to your game server
- Create Reverse Proxies with automatic HTTPS (via letsencrypt) and attach them to any port on your game servers. Uses an ``*.evlbox.io`` suboomain or your own domain.


### What management tasks are taken care of for on a Nitro Managed plan?

Sit back and relax! We'll take care of everything for you!

- Connecting your dedicated server or gaming vps to our Nitro Panel. 
- Off-site nightly backup of your game servers' MySQL databases
- OS security updates
- Uptime monitoring of critical services
- Health check monitoring on the NVME (dedicated servers only)
- Installation of custom games (games must be able to run on Linux)
- Nginx Reverse Proxy - adds HTTPS to any port on your services and allows you to set a custom domain
