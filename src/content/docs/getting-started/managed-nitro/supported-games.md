# List of Nitro Managed Services

Customers with a Nitro Managed plan are able to freely utilize this below services in the Nitro Panel. Note that some games may require you to login with a steam account to download server files.

#### Are we missing something? Contact our [help team](https://evlbox.com/help) and we may be able to add it! Note that Nitro Managed servers can only run Linux. Some Windows apps and game servers may not run properly.
