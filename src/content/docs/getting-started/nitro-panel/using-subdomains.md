# Using Subdomains

Subdomains are a simple way to get a vanity name for your game server. Instead of players connecting with the IP address and port, they can connect with just a name like stevecraft.evlbox.io. Subdomains use SRV type DNS records so even if you don't have the default game port players won't need to enter a port number (currently only supported by minecraft)

![minecraft-join-screen-example](/nitro/join.png)


:::caution
Want multiple subdomains? Contact support and we can allocate you additional subdomains free of charge (limit 5)
:::
## Creating a Subdomain 

In Nitro panel click the subdomain menu

![screenshot-select-nitro-panel-subdomain](/nitro/subdomain1.png)

Then in the dropdown choose a domain you'd like to use and then enter a name. Do not enter a server port! The port will be taken care of automatically. 

![screenshot-creating-a-subdomain](/nitro/subdomain2.png)

Depending on a players interenet provider / dns settings it may take 15-30 minutes for the name to start working, though most users can use it instantly.
