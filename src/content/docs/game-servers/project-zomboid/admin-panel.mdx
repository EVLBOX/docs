The admin panel allows users to manage player interactions, enforce server rules and adjust game settings. 

To access the admin panel, the user must first be granted admin access from the server console. See more information on admin permissions here:  [How to Add Admin permissions](/docs/game-servers/project-zomboid/admin-permissions)

### How to view the Admin Panel

1. Log in to the game as admin

2. Your character will display "Admin" next to their name and you will see an Admin button in the side panel menu. 
![admin_button.png](/docs/zomboid/admin_button.png)

3. Click on the button to open the admin panel

![admin_panel.png](/docs/zomboid/admin_panel.png)
