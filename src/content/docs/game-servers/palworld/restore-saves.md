# How to Restore Saves from Server Backups
If your save game data ever gets lost or corrupted due to the server crashing, you can restore your data from the automated server backups.

:::caution
The autmoated backups only run every 2 hours if the server is **online**. If the server is scheduled to be stopped, or has crashed, it will not create a backup slot.
:::
If you do not currently see any backup data in the nitro panel, you can manually create a backup file. More info on how to do that can be found here: 
[How to Create Backups](/docs/getting-started/nitro-panel/creating-backups)

## How to Restore Backups
1. Login to the Nitro Panel and Stop your server from the console. Once it is offline, select Backups from the menu. 

![palworldbackups.png](/docs/palworld/palworldbackups.png)

2. Click on the three dots next to the backup you want to use and select "Restore" 

![restore_backup_pal.png](/docs/palworld/restore_backup_pal.png)

3. This will bring a pop up window confiriming the back up you have selected. It will ask if you want to delete all files before storing, leave this unchecked. Click Restore.
:::caution
Do not Delete all files before restoring backup. Backup files only contain config and save files
:::
![restore_pop_up.png](/docs/palworld/restore_pop_up.png)

4. The backup restore process will show a confirmation screen. 

![restoring_confirmation.png](/docs/palworld/restoring_confirmation.png)

5. This window will close once completed, you can now return to the console and start your server.
