The console window in the Nitro Control Panel will now issue RCON commands to your Palworld Server. Follow the steps below to use RCON commands. 

## How to Reinstall your server
To take advantage of these new features, you will need to reinstall your server.
:::tip
These updates will not write over your saves or player data.
:::
1. Login to the Nitro Panel and go to the settings tab. 

![reinstall.png](/docs/palworld/reinstall.png)

2. There is a warning message about backing up data. Automatic server backups should be running for your server but you can check when the last backup ran under the backups tab. 

![palworldbackups.png](/docs/palworld/palworldbackups.png)

3. Click Reinstall Server and Yes, Reinstall on the pop up message

![reinstall_confirm.png](/docs/palworld/reinstall_confirm.png)

4. You will see message that the installer is running, when complete it will return to the settings screen. 

![wait_screen.png](/docs/palworld/wait_screen.png)

5. Go to the console tab and check to see if you server is running. If it is offline, click start to bring it online. 


## RCON Commands
1. Login to the Nitro Panel and Click on Console 
2. With the update, you will now see a line to enter commands. 

![enter_commands_.png](/docs/palworld/enter_commands_.png)
