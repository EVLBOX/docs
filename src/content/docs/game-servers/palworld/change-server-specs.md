If you are running into issues with memory leaks or need more processing power to invite more friends to your Palworld Server look no further. Here is a complete guide on how to change your Palworld server RAM and CPU. You can make changes up to 4 CPU cores or 16GB of RAM automatically. If you need additional resources beyond these, please contact us. 

![palworld-crossplay.jpg](/palworld/palworld-crossplay.jpg)

## Where to view your Server Specs

- Login to nitro.evlbox.com and in the console panel, you can see the CPU, RAM, and disk utilization in real time. If you are close to using your maximum allotment of resources, you may want to consider upgrading. 

![ram_cpu_disk.png](/palworld/ram_cpu_disk.png)

- This information can also be seen in the EVL box portal. Once you login, click on the dashboard, click manage on your server and the information is under Configurable Options.

![server_stats.png](/palworld/server_stats.png)


## Server Ram and CPU Upgrades
1. Login to portal.evlbox.com

2. Click on Dashboard and click Manage on the Server you would like to update.

![products.png](/palworld/products.png)

3. Click "Upgrade/Downgrade Options" under the Actions Menu. 

![actions.png](/palworld/actions.png)

5. On this page you can view the changes availble and their associated costs

![upgrade_options.png](/palworld/upgrade_options.png)

6. Once you have made your selections, scroll down and click continue. This will show a summary of the changes and allow you to proceed to checkout. Once you have your order confirmation, if you return to the dashboard and Manage Server, the changes will be noted and the additional resources will be immediately available. These changes will also be reflected in the Nitro Panel. 

![upgraded_server.png](/palworld/upgraded_server.png)

:::caution
If you would like more than 4 CPU cores or more than 16GB of RAM please contact us so we can make sure your current node has enough capacity to support it.
:::
## Server Ram and CPU Downgrade
1. If you have purchased additional RAM or CPU Cores and have decided that you no longer want them, you can remove them. 
2. Login to portal.evlbox.com and click on the Dashboard, and click manage server.
3. Click on "Upgrade/Downgrade Options" under the action menu and you will see a page with available downgrade changes. 

![downgrade_options.png](/palworld/downgrade_options.png)

4. Scroll down and click continue. This will show a summary of the changes and allow you to proceed to checkout. Once you have your order confirmation, the changes will be noted in the dashboard and in the Nitro Panel.
