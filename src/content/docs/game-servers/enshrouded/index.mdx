Enshrouded is a co-op survival action RPG for up to 16 players, set in a voxel world you dig, build and terraform. You wake as a Flameborn, push back the Shroud, and rebuild Embervale with your friends.

![Enshrouded key art](/docs/enshrouded/header.jpg)

## Before You Start

Four things about Enshrouded servers catch people out. All four are worth knowing before you share your server with anyone.

**There are three passwords, not one.** Enshrouded has no single server password. Your server has an **Admin**, a **Friend** and a **Guest** password, and the one you hand someone decides what they can do. Leave the Guest password empty and the server is public. See [Admin, Friend and Guest Roles](/docs/game-servers/enshrouded/server-roles).

**Password changes apply through a reinstall.** Changing a role password or a reserved-slot count takes effect via **Settings**, then **Reinstall Server**. That keeps your world, saves and files. Every other setting applies on a normal restart.

**Custom difficulty settings only count when the preset is Custom.** Default, Relaxed, Hard and Survival use the game's built-in profiles and ignore every slider under them. See [Server Settings](/docs/game-servers/enshrouded/server-settings#difficulty-preset).

**Personal quest progression is a player setting, not a server setting.** Each player turns it on in their own journal. There is nothing to configure in the panel. See [Quest Progression](/docs/game-servers/enshrouded/quest-progression).
