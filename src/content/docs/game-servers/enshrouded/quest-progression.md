A recent news post indicated that the development team is working on changes to player quest progression. Currently, quest progression is saved on a world or server basis. Any new players that join will be able to jump into the latest quests right away and can skip any tutorials. 

Upcoming changes will allow players to change this in case they would like to complete every quest themselves. 


Below is a snippet of the news article. Once these changes have been implemented, this page will show how to switch between the default server group progression and individual progression.
