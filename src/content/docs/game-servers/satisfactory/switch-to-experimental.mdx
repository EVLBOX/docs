# **How to Switch to the Experimental Branch for Your Game Server**

The **Experimental Branch** gets new Satisfactory builds before they reach everyone else. You don't need it to play Satisfactory 1.2, which is on the stable **public** branch.

:::caution
Experimental builds can have bugs and can break mods. [Download a copy of your saves](/docs/game-servers/satisfactory/manage-saves) before you switch. Your game also needs to be on the same branch as your server, so everyone joining will have to switch too.
:::

### **Switch to experimental**

1. Log in to the [Nitro Panel](https://nitro.evlbox.com) and open your server.
2. Go to the **Startup** tab and set **Game Branch** to **experimental**.
3. Make sure **Automatic Updates** is on.
4. Restart your server. It downloads the experimental build as it starts.

![Startup tab showing the Game Branch setting](/docs/satisfactory/startup-variables.png)

### **Switch back to stable**

Follow the same steps and set **Game Branch** to **public**. Back up your saves first here too.

### **Troubleshooting**

If the branch change isn't taking effect, go to the **Settings** tab in the Nitro Panel and select **Reinstall**. This reinstalls the game files for the selected branch and keeps your saves.

If the game files seem broken, turn on **Validate Server Files** on the **Startup** tab, restart your server, then turn it back off. It makes startup slow, so don't leave it on.
