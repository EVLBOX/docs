# **How to Switch to the Experimental Branch for Your Game Server**

Switching your server to the **Experimental Branch** allows you to access the latest features and updates that are in development for Satisfactory. Follow these steps to switch your server’s game version to **Experimental** and get started with the latest experimental updates.

### **Step-by-Step Instructions**:

1. **Log in to the Nitro Panel**:
   - Go to the [Nitro Panel](https://nitro.evlbox.com) and log in to your account.
   - Once logged in, open your **game server** by selecting it from your dashboard.

2. **Set the Branch to Experimental**:
   - In the **Server Configuration** section, go to the **Startup** tab.
   - Find the **Branch Name** setting and change it to **“experimental”**.
   - This will ensure your server is using the latest experimental version of Satisfactory.

3. **Enable Automatic Updates**:
   - Make sure that **automatic updates** are enabled. This setting will ensure that your server is automatically updated to the latest version of the experimental branch when updates are released.
   - Ensure that the **Startup Mode** is set to **FactoryServer** (which is the default setting).

4. **Restart Your Server**:
   - After making the necessary changes, **restart your server** to apply the new settings. The server will now run on the **experimental branch** and automatically download any updates when available.

### **Troubleshooting**:

If you're having trouble switching branches, or if the changes aren’t taking effect, try these steps:

- Go to the **Settings** tab in the Nitro Panel and select **Reinstall**.
- This will re-run the **steamcmd install process**, but it will **not overwrite** your **game saves**. Your save files will remain intact, and the server will update to the **experimental branch** version.

---

### **Why Switch to the Experimental Branch?**

Switching to the **Experimental Branch** lets you experience the **latest features** and **fixes** before they are officially released. However, since this version is still in development, it may contain **bugs** or **unfinished features**. If you prefer a more stable experience, it’s best to wait for the **stable release**.
