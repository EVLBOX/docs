Valheim is a brutal exploration and survival game for up to 10 players, set in a procedurally generated Norse purgatory. Build a longhouse, raise a longship, and go and get killed by something with antlers.

![Valheim key art](/docs/valheim/header.webp)

## Before You Start

Four things about Valheim servers catch people out. All four are worth knowing before you touch a setting.

**Leave crossplay on.** It's on by default and it should stay that way. Turning it off currently produces a server that looks perfectly healthy — it appears in the browser and answers queries — but that nobody can actually join, Steam players included. See [Crossplay](/docs/game-servers/valheim/server-settings#crossplay) for the detail.

**Public needs a password.** Valheim refuses to list a password-free server in the public browser. If you clear the password and leave **Public Server** on, your server starts unlisted rather than failing — players join by address or join code instead. See [Password and visibility](/docs/game-servers/valheim/server-settings#password-and-visibility).

**Your password must not appear inside your server name.** Valheim will not start at all if it does. Naming your server `Odins Hall` and setting the password to `hall` is enough to trigger it.

**World modifiers stick to the world, not the setting.** Changing a modifier back to `default` doesn't undo it — `default` means "send no flag", which leaves whatever the world already has saved. To genuinely reset them, apply a **World Preset**.
