7 Days to Die is a survival horde crafting game set in a fully destructible voxel world. Scavenge, build, and fortify by day, then hold your base together when the blood moon horde arrives.

![header.jpg](/docs/7dtd/header.jpg)


## Before You Start

Three things about 7 Days to Die catch people out. Worth knowing up front.

**Difficulty is now one code.** As of V3.0, difficulty, XP, loot, zombie speed and blood moon frequency are no longer separate settings. They're all packed into a single **Sandbox Code** you build in-game and paste into the panel. See [Server Settings](/docs/game-servers/7-days-to-die/server-settings).

**Mods and console crossplay don't mix.** Crossplay needs EasyAntiCheat on. Most mods need it off. Pick one before you start a world — switching later usually means a fresh save.

**Judge performance on day 7, not day 1.** An idle server tells you nothing. If things get rough, lowering **Max Allowed View Distance** is the fastest fix.
