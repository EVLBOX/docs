# How to Upload a game save to your Factorio Server
Play your favorite factory with friends!

## Find your Save Game File and Upload it
1. Save games are stored as a .zip file. You can find them in your folder directory under C:\users\you\appdata\roaming\factorio\saves
![saves.png](/saves.png)
2. Log in the nitro panel and stop your server.
3. Then in the Files Tab, click on the saves folder. Here you can upload the .zip file of the save you would like to use.
![file_saves.png](/file_saves.png)
4. You can upload from the file tab or use a FTP like cyberduck. 


## Update Your Server 
1. In the Startup Tab of the Nitro Panel Scroll Down to the Save Name Entry Field
2. Enter the name of the save you would like to use. 
![save_name.png](/save_name.png)
3. Click out of the Save Name Field and Start your server. 
4. Join your server and the game will use the settings, map and progress from the selected save.
