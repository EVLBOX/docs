# How to Connect to your Factorio Server
## Find your Server IP Addresss
1. In the [Nitro Panel](https://nitro.evlbox.com/) find your factorio server and click manage server. 
2. Make sure your server is running and online, then copy the full hostname.
![hostname.png](/docs/factorio/hostname.png)

## Connect to your Server in Factorio 
1. In Factorio Select Multiplayer. 
![multiplayer.png](/docs/factorio/multiplayer.png)
2. In this menu, select Connect to address
3. Paste the host name you copied here and click connect. 
![connect.png](/docs/factorio/connect.png)
4. If successful, you will be prompted to create a unique Username or log in to your Factorio.com account
![create_account.png](/docs/factorio/create_account.png)
5. Invite friends with the hostname or create a subdomain name to share. 
6. After you quit and want to rejoin your game, you can choose to reconnect from the main menu. 
![continue_join.png](/docs/factorio/continue_join.png)

If you have any questions please feel free to reach out to us in the support channel on Discord!
